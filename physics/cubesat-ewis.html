Purpose

Everything Together

A complete Electrical Wiring Interconnect System for a 3U CubeSat. This integrates EVERY previous module: DC analysis, wire sizing, EMI separation, power distribution, connectors, thermal analysis, and evolutionary routing -- on one real system.

The System

Subsystems

EPS: Solar panels + batteries + regulators (28V -> 5V/3.3V)

OBC: Processor + memory + I2C/SPI buses

ADCS: Magnetorquers + sun sensors + gyros

COMM: Transceiver + antenna + amplifier

Payload: Camera or science instrument

Design Decisions

8 connectors | ~52 wires | Dual-string power | AS50881 compliant

Key Insight: This project IS what Artifact was built to design. You just designed it from first principles with your own tools. The physics is the same at CubeSat scale or full-aircraft scale -- only the wire count changes (52 vs 50,000).

Historical

CubeSat Standard (1999)
Created by Bob Twiggs (Stanford) and Jordi Puig-Suari (Cal Poly). Originally for education. Now used for real missions. Planet Labs operates 200+ CubeSats for daily Earth imaging. NASA JPL MarCO (2018): first CubeSats to deep space.
