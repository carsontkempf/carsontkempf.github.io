CORS Diagnostics

Test CORS preflight and analyze network communication issues. Run this if you see CORS errors in the console.

What This Tests:

  • OPTIONS preflight request to proxy endpoint
  • Access-Control-Allow-Origin header presence
  • Access-Control-Allow-Headers validation
  • Simple GET request (no preflight)
  • Network connectivity to cloudprototype.org
  • Server-side CORS configuration verification

Secrets Configuration Diagnostics

Diagnose secrets configuration issues. This will check if your API keys are properly configured and provide actionable recommendations.

What This Checks:

  • Whether the secret exists in the project
  • All available secret names in the project
  • Secret configuration (provider, base_url, auth headers)
  • SDK token origin configuration
  • Project access expiration status
  • Actionable recommendations to fix issues

Systematic Test Framework

Comprehensive multi-layer diagnostic test suite. Runs 18+ tests across 5 layers to identify all configuration and connectivity issues.

Test Layers:

  • Layer 1: Network Connectivity (DNS, SSL, HTTP reachability)
  • Layer 2: CORS Configuration (preflight, headers, policies)
  • Layer 3: Authentication Flow (origin validation, tokens)
  • Layer 4: Secrets Configuration (existence, structure)
  • Layer 5: End-to-End Integration (full API calls)
